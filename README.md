# StorySprout

StorySprout is an AI reading passage generator designed to help teachers quickly create customized reading materials for their students. The platform is centered on teacher control, allowing educators to shape passages based on grade level, length, text type, topic, word list, and other instructional needs. This direction aligns with the needs identified in stakeholder input from a reading specialist, including the importance of teacher-selected topics, vocabulary control, standards alignment, and flexible formatting for classroom use.

## Purpose

Teachers often need short, targeted reading materials that match a student’s reading level, interests, and instructional goals. Existing tools can require heavy prompt writing, repeated revision, or extra formatting work. StorySprout is intended to simplify that process by giving teachers a structured way to generate passages while keeping key decisions in their hands. Teacher control is a core priority of the project, especially around passage characteristics and post-generation customization.

## Planned Features

### Story generation inputs
Teachers will be able to generate a passage using the following form inputs:

- **Grade Level** (`__ of Grade __`)
  - Position in school year: Beginning / Middle / End
  - Grade: K–12
- **Word Count**
  - 25–50 words
  - 50–75 words
  - 75–100 words
  - 100–150 words
  - 150–200 words
  - 200–250 words
  - 250–400 words
- **Text Type**
  - Fiction
  - Nonfiction
- **Topic**
  - One-line text entry
- **Word List**
  - Text entry
  - Supports pasted content
- **Additional Requirements**
  - Open text input

### Story viewing and customization
After a passage is generated, teachers will be able to:

- View the generated story
- Adjust **font size**
- Adjust **font style**
- Adjust **line spacing**
- Request regeneration based on **teacher-defined criteria**
- Save stories for later use
- Revisit previously saved stories

## Design Priorities

StorySprout is being designed around several instructional priorities:

- Giving teachers meaningful control over generated content
- Supporting classroom-relevant customization rather than one-size-fits-all output
- Making it easier to tailor passages to student needs and interests
- Reducing the amount of manual prompt engineering teachers need to do
- Supporting practical classroom use through readable formatting and revision options

## Project Status

StorySprout is currently in the planning and design stage. No features are implemented yet. This README describes the intended direction and planned functionality of the application.

- **HTML**

## Intended Users

StorySprout is primarily intended for teachers who need flexible, customizable reading materials for classroom instruction or individual student support. It is also being developed as part of an academic project.

## Vision

The goal of StorySprout is not just to generate reading passages, but to give teachers a faster and more structured way to create materials that still feel instructionally intentional. Rather than replacing teacher judgment, the app is meant to support it.
